Pure-infrastructure phase (no UI). The MVP "vertical slice" is the **complete secured per-user data path**; this plan builds the data-store half of it (the profiles table + private photo bucket that Phase 3's onboarding form will write to). Framed as an infrastructure outcome:

> **As** the Campus Crush application, **I need** a dedicated, RLS-protected `profiles` row per student plus a private per-user photo bucket, **so that** onboarding can persist private data that only its owner (and the review team via signed URLs) can access.
